# Tochiwears — Demo E-commerce Store

This repository contains a starter Next.js + TypeScript + Tailwind project scaffold for Tochiwears — a premium fashion accessories store demo.

Features included in the scaffold:
- Responsive pages: Home, Shop, Product, Cart, Checkout, Account, Admin
- Header and Footer components with Collections menu
- Mock product data and API routes
- Tailwind CSS setup
- Paystack payment stub (for integration)

Quick start:

```bash
# install dependencies
npm install

# run dev server
npm run dev
```

Notes:
- This is a starter scaffold. Replace mock APIs with a real backend (Postgres) and integrate Paystack for production.
- Nigerian-specific fields, currency (₦), and Paystack-ready flow are included in design and placeholders.
